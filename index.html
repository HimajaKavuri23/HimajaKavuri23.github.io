01 — The Pipeline

Before you can answer anything, you need data you can actually trust.

Intrinsic IQ is a stock analysis platform built to answer one question: what is this company actually worth? The first challenge wasn't the model — it was the pipeline. Live financials, earnings transcripts, API inconsistencies. Getting clean, structured data into a reproducible flow is the unglamorous work that makes everything else possible.

Both layers surface side by side in a React dashboard — so every conclusion traces back to its source.

02 — The Model

A model is only useful if you can explain why it works.

Stroke risk prediction from patient records — 93% accuracy, published at IEOM World Congress 2026. The domain is clinical, but the method is identical to financial modeling: select the right features, handle class imbalance, validate rigorously, and make the output legible to someone who didn't build it.

Imbalanced dataset addressed with SMOTE. Five algorithms benchmarked via cross-validation — XGBoost won on AUC. SHAP values then translated the model's output into feature-level explanations: not just a risk score, but the specific factors driving it. That explainability layer is what makes a model usable in practice.

03 — The Cost

Accuracy is a starting point. The real question is what does it save?

Hospital length-of-stay prediction using MIMIC-III ICU data. On the surface it's a clinical problem — underneath it's resource forecasting and cost optimization. I translated model performance into dollar terms: what does a one-day improvement in prediction accuracy actually mean for bed allocation?

Admission-time features engineered from diagnosis codes, lab trends, and comorbidity counts. Random Forest trained with time-based validation splits to simulate real deployment. R-squared and MAE converted into cost estimates per bed-day — framing the output for an operations audience, not just a data one.

04 — The Market

The signal is already there. You just have to know where to look.

Millions of Google Play Store reviews, analyzed for competitive intelligence. What users write in app reviews — when aggregated, structured, and scored — becomes the kind of market signal that belongs in a due diligence report or investment thesis. Unstructured data is only a problem until you build the right lens.

NLTK preprocessing pipeline into LDA topic modeling — surfacing what users actually care about versus what product teams assume. VADER sentiment scoring aggregated by topic, version, and competitor, producing a time-series view of perception shifts. Output: a filterable Plotly dashboard built for an analyst audience.
